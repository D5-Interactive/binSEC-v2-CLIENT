# binSEC v2 CLIENT

A modpack for Minecraft, designed for use with Prism Launcher.

## Installation

1. Go to the [Releases](https://github.com/D5-Interactive/binSEC-v2-CLIENT/releases) page
2. Download the latest `binSEC-v2-CLIENT.zip` from the release assets
3. Open Prism Launcher
4. Click **Add Instance** → **Import from ZIP**
5. Select the downloaded `binSEC-v2-CLIENT.zip`
6. Launch and play!

## Modpack Contents

This modpack includes a curated selection of mods for an enhanced Minecraft experience. See the release notes for the full mod list and version information.

## Updates

Check the [Releases](https://github.com/D5-Interactive/binSEC-v2-CLIENT/releases) page for updates. Simply download the new ZIP and import it as a new instance in Prism Launcher.
